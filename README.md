# Root3D

Root3D is a 3D engine project that focuses on platform independence. 
Many parts of the engine are still in development and not yet finished.

Currently, the engine can be built for Android and Windows. 
Future plans include adding support for more platforms. 


## Environment Setup
1. Ensure Python3 is installed on your system.
2. Install Visual Studio 2019 for Windows development.
3. Install Android Studio for Android development.
4. Run the `win_pack_assets` script in the `tools` directory to package resources.

## Desktop Build
1. Navigate to `projects\windows`.
2. Open the project solution in Visual Studio.
3. Build and run the project.

## Android Setup
1. Navigate to `projects\android`.
2. Open the project solution in Android Studio.
3. Build and run the project.
